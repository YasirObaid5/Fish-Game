# Rock surface textures

Source: [Rock Face 03, Poly Haven](https://polyhaven.com/a/rock_face_03).
License: [CC0 / public-domain dedication](https://polyhaven.com/license).
Downloaded unmodified from Poly Haven on 2026-09-06. Source download checksums were verified.

- rock-color.jpg: rock_face_03_diff_2k.jpg, MD5 657add9e8a8dffaeed19bdfc58078b59
- rock-normal.jpg: rock_face_03_nor_gl_2k.jpg, MD5 279b33e71ae6275cafa24e6597024c98
- rock-arm.jpg: rock_face_03_arm_2k.jpg, MD5 f7999b2d14ebbea91e1a5adfb7beabc3

The three 2K texture maps supply surface color, OpenGL normals, and packed ambient occlusion/roughness/metalness. They are bundled locally; the game makes no runtime requests to Poly Haven. Meshes, world layout, animation and game code are authored separately for this game. No Subnautica assets are used.
