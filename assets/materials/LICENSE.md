The three 2K texture maps supply surface color, OpenGL normals, and packed ambient occlusion/roughness/metalness. They are bundled locally; the game makes no runtime requests to Poly Haven. Meshes, world layout, animation and game code are authored separately for this game. No Subnautica assets are used.
